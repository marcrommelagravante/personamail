# PersonaMail Brand Guidelines

> Version: 0.4 — Selected Visual Direction

## Brand Identity

**PersonaMail** is a modern communication workspace that helps users communicate naturally and consistently with different people.

**Positioning:** Relationship-aware communication.

**One-line Product Pitch:** **The right words for every relationship.**

**Canonical Tagline:** **Every conversation remembers who it's for.**

## Brand Principles

- Human-first
- Personal
- Professional
- Calm
- Reliable
- AI-powered behind the scenes

PersonaMail should feel like a communication product, not an AI tool.

## PersonaMail Is Not

- An AI chatbot
- A generic AI email generator
- A prompt playground
- A futuristic robot interface
- An AI-first website

## Brand Personality

- Calm
- Helpful
- Confident
- Clean
- Friendly
- Professional

## Voice & Tone

### Prefer
- Compose
- Improve
- Review
- Summary
- Communication Style

### Avoid
- AI Generator
- AI Rewrite
- AI Grammar
- Magic Prompt
- Super AI

## Visual Direction

PersonaMail should have a modern, minimal, human-centered SaaS aesthetic.

### Design Principles
- Large whitespace
- Strong typography
- Minimal color palette
- Fast, subtle interactions
- AI stays in the background
- One primary action per screen

### Avoid
- Robot icons
- Purple AI gradients
- Sparkles
- Neon effects
- Unnecessary glassmorphism
- Excessive visual effects

### Prefer
- Conversation
- Contact
- Envelope
- Identity
- Connection

## Color System

### Selected: Option B

This is the official PersonaMail color direction.

- **Primary:** `#0F172A`
- **Accent:** `#7CE3FF`
- **Background:** `#F8FAFC`
- **White:** `#FFFFFF`

### Color Usage

**Primary — `#0F172A`**
- Main text
- Headings
- Navigation
- Strong UI elements
- Dark surfaces when needed

**Accent — `#7CE3FF`**
- Primary highlights
- Links
- Active states
- Selected states
- Important brand details
- Logo/wordmark accent

**Background — `#F8FAFC`**
- Main application background
- Page surfaces

**White — `#FFFFFF`**
- Cards
- Inputs
- Modals
- Elevated surfaces

### Color Rules

- Accent should guide attention, not dominate the interface.
- Do not use gradients as a default design pattern.
- Do not introduce random brand colors without a design-system reason.
- Maintain sufficient contrast and accessibility.

## Typography

### Selected: Geist

**Geist is the official PersonaMail typeface.**

Use Geist consistently across the product:
- Logo/wordmark supporting typography
- Landing page
- Dashboard
- Navigation
- Headings
- Body text
- Buttons
- Forms
- Labels and captions

Typography should feel clean, modern, readable, and professional without appearing overly futuristic.

## Design System

### Spacing
- Use a consistent 8px spacing system.
- Prefer generous whitespace.
- Avoid crowded layouts.

### Border Radius
- Small: 8px
- Medium: 12px
- Large: 16px
- Avoid excessive pill-shaped UI.

### Borders
- Prefer subtle 1px borders.
- Avoid heavy outlines.

### Shadows
- Use soft, restrained shadows.
- Avoid glowing or floating-card effects.

### Buttons
**Primary**
- Clear label
- Solid primary/accent treatment
- Medium radius
- No gradients

**Secondary**
- Neutral/white surface
- Subtle border

Avoid:
- Glowing buttons
- Gradient buttons
- Excessive pill buttons

### Cards
- Clear hierarchy
- White or appropriate surface
- Subtle border
- Minimal shadow
- Consistent radius

### Icons
- Use one consistent icon library.
- Prefer Lucide Icons.
- Do not mix unrelated icon styles.
- Do not use emoji as interface icons.

## Motion

Animations should feel subtle and purposeful.

- Prefer approximately 150–250ms transitions.
- Use smooth ease-out motion.
- Animate meaningful state changes.
- Avoid constant movement.
- Avoid bouncing UI.
- Avoid glowing or pulsing AI effects.
- Avoid decorative particle effects.

## AI Interface Rules

AI should feel like an integrated capability, not the identity of PersonaMail.

### Avoid
- “✨ AI Magic”
- “Powered by AI” everywhere
- Robot avatars
- AI chat as the primary workflow
- Prompt boxes as the main interface
- “AI is thinking...” animations

### Prefer
- Contextual suggestions
- Inline improvements
- Suggested wording
- Automatic personalization
- Subtle generation states
- Human-readable actions such as Compose, Improve, Review, and Summary

## UX Principles

- Ask about people, not prompts.
- Reduce typing.
- Keep interfaces calm.
- Never overwhelm users.
- AI assists without interrupting.
- Every page should have one primary action.
- Prefer contextual actions over configuration-heavy workflows.

## Loading & Empty States

### Loading
Prefer skeleton loading for normal page content.

For AI generation, use a subtle status such as:
> Preparing your message…

Avoid robotic or theatrical AI loading states.

### Empty States
Example:
> **No contacts yet**  
> Add someone to start building their communication profile.

Avoid generic AI-themed empty states.

## Responsive Design

PersonaMail should work across:
- Desktop
- Laptop
- Tablet
- Mobile browser

Desktop is the primary experience. Mobile layouts should simplify the experience rather than simply shrink the desktop layout.

## Accessibility

- Maintain readable contrast.
- Never use color as the only indicator.
- Use visible labels for inputs.
- Provide clear button labels.
- Support keyboard navigation.
- Maintain visible focus states.
- Use appropriate interactive target sizes.
- Respect reduced-motion preferences.

## Product Navigation Direction

- Compose
- Contacts
- Templates
- History
- Settings

AI features should appear naturally inside these workflows instead of dominating the interface.

## Logo Direction

The logo should communicate communication, identity, and relationships.

### Explore
- Abstract P
- Envelope + Profile
- Conversation + Mail
- Contact Card + Envelope

### Avoid
- Feathers
- Robot imagery
- Magic wands

The selected logo should work on both light and dark surfaces and remain recognizable at small sizes.

## Brand Goal

Users should describe PersonaMail as:
> **A communication workspace that remembers how I communicate with different people.**

Not:
> An AI email generator.
